# Goal and acceptance criteria

Evaluate complete agent systems, including single-agent and multi-agent configurations,
on the same versioned tasks. Support local repeatable experiments, regression comparison,
category/tag breakdowns, evidence-based grading, duration and aggregate usage reporting.

Initial acceptance:

- Approximately twelve small tasks across data, coding, research and tool workflows.
- Deterministic isolated environments and documented capability/network requirements.
- Positive, alternate-answer and negative verifier tests; no claim of human verification.
- My AI Employee plus another actual agent implementation, not scripted substitutions.
- At least one actual single/multi comparison and repeated trials.
- Local HTML report with filters, comparisons, detailed checks and available traces; JSON export.
- Success, failure and unscorable counts include every scheduled trial; errors never vanish.
- Documentation, automated checks, real results and known limitations.

Harbor owns task execution/environment lifecycle. This project owns a small suite, adapters,
experiment configuration and reports. Start with a compatibility spike. Version dependencies
and record agent/environment/suite fingerprints. Never claim the small suite proves general
intelligence, multi-agent superiority or production readiness.

My AI Employee's internal status is diagnostic, not the benchmark grade. Subscription usage
has unknown monetary cost unless a documented rate is explicitly supplied. Agent self-report
is not trusted evidence for final success or protected-state preservation.
