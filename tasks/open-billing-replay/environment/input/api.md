solve({events, as_of}) returns {tenant: integer_balance}. Do not mutate arguments. Events have tenant, id, positive revision, integer at, kind (invoice/refund), optional deleted. Copies with the same tenant/id/revision are identical. Invoice lines have unique id, nonnegative integer unit cents, quantity, active and positive period; 0 <= active <= period. tax_bps is nonnegative integer basis points; invoice discount is optional nonnegative integer cents. Refunds have invoice (id) and line_ids (possibly duplicated or unknown). Empty lines are valid.
